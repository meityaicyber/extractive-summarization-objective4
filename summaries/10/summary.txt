As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the National Informatics Centre, Scientist B Recruitment 2026(call letter module) web application from 03 August 2026 to 14 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report, and it is observed that all the previously reported vulnerabilities are mitigated.

The issue requires extensive code changes across the application, and it is not feasible to incorporate all such changes immediately. The reported vulnerability pertains to the pre-production environment, which is not internet-facing and is used only for internal testing. Our application currently uses ASP.NET 4.6.1, for which Microsoft has ended security updates and we accept the risks associated for the same.

Proper implementation of HTTP Security Headers like Content Security Policy (CSP), X-XSS-Protection, X-Frame-Options, etc. is recommended on the production server. The latest and stable TLS version deployment is suggested on the production server for further enhanced security. Any framework, library and/or server running with the older version must be upgraded with the latest version, security plug-ins and/or add-ons.
