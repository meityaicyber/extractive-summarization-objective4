This Closure report contains the findings of vulnerability assessment of Xtreme Digital Signage web application conducted for Xtreme Media Private Limited.

The report describes a session hijacking vulnerability where an attacker can copy the session ID from a right-hand side browser and paste it into a left-hand side browser to hijack the session. Its unauthorized disclosure could seriously and adversely impact the owner, its stakeholders, its business partners, and/or its customers leading to legal and financial repercussions and adverse public opinion.

The report states that session hijacking is not possible here, indicating the vulnerability has been closed. No further recommendation is provided. As per the client's statement, The application currently uses inline JavaScript click event handlers (onclick) within certain existing UI components. These handlers are tightly coupled with the application's existing frontend functionality and are required for specific user interactions. Therefore, removing inline event handlers at this stage may impact existing application functionality. Any security risks related to this behavior lie with the client (Xtreme Media Private Limited).
