As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the Easy Connect web application from 03 July 2026 to 12 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report, and it is observed that all the previously reported vulnerabilities are mitigated.

The report states that the Brute Force vulnerability was initially open, then closed after revalidation of the fixes implemented to mitigate the previously reported vulnerabilities. SSL/TLS Certificate Supports Older versions, CBC and Weak Cipher Algorithms. Lack of Security Headers. Missing Cookie Attribute.
