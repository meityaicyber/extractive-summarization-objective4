As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the Onboarding System web application from 31 July 2026 to 11 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

The Content Security Policy (CSP) is intentionally configured to retain unsafe-inline and unsafe-eval, as removing these directives would significantly impact the website’s structure and core functionality. Required security headers have also been implemented to prevent clickjacking attacks, and other relevant security patches and headers are in place to reduce overall risk exposure. The CSP is intentionally configured to retain unsafe-inline and unsafe-eval directives, which increases the risk of XSS attacks despite the presence of input validation and other security headers.

Implement a properly configured Content Security Policy that does not retain unsafe-inline and unsafe-eval directives, and ensure comprehensive input validation mechanisms are in place to prevent Cross-Site Scripting (XSS) attacks.
