As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the TheLifeHMS web application from 07 July 2026 to 10 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

Certain existing components cannot be upgraded immediately because of application compatibility, dependency, and stability requirements. These items are not being disregarded; rather, they are being formally identified as Business/Technical Exceptions based on the current application architecture and operational requirements. Wherever possible, appropriate compensating controls, access restrictions, infrastructure-level controls, monitoring, secure configuration, and periodic review will be maintained to reduce the associated risks. We request the Audit Team to review the above observations under the Exception / Risk Acceptance category, subject to the organization's applicable information security and risk-acceptance process. Application compatibility, dependency, and stability requirements hinder immediate upgrades or replacements of existing components.

Consider upgrades or replacements of vulnerable and outdated components as part of the application modernization and version-upgrade roadmap. Implement compensating controls, access restrictions, infrastructure-level controls, monitoring, secure configuration, and periodic review to reduce associated risks. Review and adjust the CORS configuration to restrict allowed origins, implement proper validation, and apply compensating controls such as host validation and infrastructure-level restrictions.
