As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the E-SAM (E-system of Assets Management) web application from 12 January 2026 to 11 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

Failure to Invalidate session after password change. The legacy ASP.NET Web Forms architecture and reliance on inline JavaScript and dynamically generated scripts make it difficult to implement strict security headers without extensive code refactoring. The use of older TLS versions, CBC, and weak cipher algorithms on the staging server poses a security risk, potentially allowing downgrade attacks or exploitation of known vulnerabilities in older cipher suites.

Implement security headers such as Content Security Policy (CSP), X-Content-Type-Options, X-Frame-Options, and others to prevent various web-based attacks. Enable TLS 1.3 and disable support for older TLS versions, CBC, and weak cipher algorithms on the production server. Implement the Mobile OTP and Email OTP integration to enable the 'Forgot Password' functionality.
