As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the State Level MSME Portal, Meghalaya web application from 14 July 2026 to 11 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

Private IP Disclosure. Use of Weak Cipher Suites. The finding is identified as 'Vulnerable and Outdated Components' with a Low severity rating. The client development organization provided justification for closure via email dated 11-08-2026, stating that unsafe inline scripts/styles are mitigated through a layered approach: frontend uses CSP headers to disallow inline scripts/styles, React components avoid inline usage, and dynamic HTML is sanitized; backend implements XSSRequestWrapper and GlobalSanitizationFilter to sanitize headers, parameters, and request bodies, with separate validation for multipart uploads; security headers including CSP, X-Content-Type-Options, X-Frame-Options, and X-XSS-Protection are enforced. The client development organization mitigated the risk through layered security controls, including Content Security Policy headers, sanitization filters, and security headers, which block unsafe inline content and validate inputs at both frontend and backend levels.

Implement Content Security Policy headers to disallow unsafe inline scripts and styles, ensure React components avoid inline `<script>` or `<style>` usage, sanitize all dynamic HTML before rendering, implement XSSRequestWrapper and GlobalSanitizationFilter to sanitize headers, parameters, and request bodies, validate multipart uploads for type and size, and enforce security headers including CSP, X-Content-Type-Options, X-Frame-Options, and X-XSS-Protection.
