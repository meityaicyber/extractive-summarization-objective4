As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the OJEE Counselling 2026 for LE courses-Working Professionals-Integrated MBA - Candidate web application from 06 August 2026 to 14 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

Vulnerable and Outdated Components. Security Logging and Monitoring Failures were identified as open during the initial assessment and subsequently closed after revalidation. Misbehaving application due to the implementation of cookie path.
