As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the BitSecure Security Information and Event Management (SIEM) Application web application from 08 July 2026 to 11 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

The SSL/TLS certificate supports older versions and CBC ciphers, which are considered weak and insecure.

Any framework, library and/or server running with the older version must be upgraded with the latest version, security plug-ins and/or add-ons. The latest and stable TLS version deployment is suggested on the production server for further enhanced security. Proper implementation of HTTP Security Headers like Content Security Policy (CSP), X-XSS-Protection, X-Frame-Options, etc. is recommended on the production server. Implementation of Secure, HTTP Only and Same Site attributes on session cookies is recommended on the production server. Web application should be behind a Web Application Firewall (WAF) for an added layer of protection against attempted attacks.
