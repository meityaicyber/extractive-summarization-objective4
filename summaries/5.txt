As part of the Web Services Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the EVC Income Tax API Web Services from 04 August 2026 to 12 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the Web Services security audit report and it is observed that all the previously reported vulnerabilities are mitigated.
