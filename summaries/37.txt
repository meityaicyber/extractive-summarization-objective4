As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the KSEB web application from 14 July 2026 to 07 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report and it is observed that all the previously reported vulnerabilities are mitigated.

The development team retained 'unsafe-inline' in the CSP to maintain compatibility with third-party UI libraries that generate inline style attributes, avoiding the need for extensive refactoring of the application's HTML, JavaScript, and UI components. We are aware of the associated security, maintenance, and support risks of continuing with the current version. At present, the application cannot be upgraded immediately as the existing applications are currently running on the same Python version. The application is currently running on Python 3.10.12, which is approaching its End of Life in October 2026, creating security, maintenance, and support risks.

Replace 'unsafe-inline' with CSP nonces or hash-based policies for inline styles, and refactor the application's HTML, JavaScript, and UI components to eliminate the need for inline style attributes generated by third-party libraries. The application should be upgraded to a supported version of Python as soon as possible to mitigate security, maintenance, and support risks.
