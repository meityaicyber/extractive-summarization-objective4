As part of the Web Application Security Audit proposal, AKS IT’s Security Consultants conducted the security audit of the KVS & NVS Recruitment Drive 2025 Post Wise Organization and Region preference submission web application from 12 August 2026 to 13 August 2026. A grey box assessment was performed to identify the vulnerabilities defined by the CERT-In Guidelines, NIC Guidelines, OWASP standard and other best practices. This is the final level of the web application security audit report, and it is observed that all the previously reported vulnerabilities are mitigated.

Misconfigured Content Security Policy (CSP) configuration in the web application. SSL/TLS Certificate Supports Older version, CBC and Weak Cipher Algorithms. The reported vulnerability pertains to the pre-production environment, which is not internet-facing and is used only for internal testing. Our production environment is already configured to disable legacy protocols and weak CBC/other deprecated cipher suites. The application currently uses ASP.NET 4.6.1, for which Microsoft has ended security updates and we accept the risks associated for the same.

The latest and stable TLS version deployment is suggested on the production server for further enhanced security. Upgrade the framework, library and/or server running with the older version with the latest version, security plug-ins and/or add-ons.
